# ConsoleModbus

Полнофункциональный пример Modbus TCP: сервер (симуляция ПЛК) и асинхронный клиент, реализованные на .NET 10 с использованием ModbusRx.

## Что сделано

### Server (Modbus TCP Slave)
- **Циклическое управление Coils**: Coils[0..9] последовательно включаются (0→1→...→9), затем выключаются (9→8→...→0) в цикле
- **Типизированные Holding Registers**: поддержка разных типов данных:
  - **INT** (адреса 0-1): 16-битные целые числа (0..65535)
  - **REAL** (адреса 2-3): 32-битные числа с плавающей точкой (IEEE 754)
  - **STRING** (адреса 4-6): текстовые данные (6 символов = 3 регистра, ASCII-кодированные)
  - **DATE** (адреса 10-11): дата/время в формате UNIX timestamp (4 байта = 2 регистра)
  - **DWORD** (адреса 12-13): 32-битные целые числа без знака (0..4,294,967,295)
  - **Дополнительные INT** (адреса 14-19): примеры целых чисел
- **Управление через класс `ModbusServerDataManager`**: инкапсулирует всю логику симуляции данных

### Client (Modbus TCP Master)
- **Асинхронное чтение данных**: не блокирует главный поток, использует async/await
- **Класс `ModbusClientDataReader`**: инкапсулирует логику чтения Coils и Registers
- **Класс `RegistersDecoder`**: декодирует raw регистры в типизированные данные (INT, REAL, STRING, DATE, DWORD)
- **Красивый форматированный вывод**: таблица переменных с обновляемой областью консоли
- **Обработка ошибок**: корректное логирование ошибок подключения и чтения

## Как запустить

### 1. Запуск сервера
```bash
cd Server
dotnet run
# или в Visual Studio: нажать F5 и выбрать Server
```

Сервер запустится на `127.0.0.1:502` (требует прав администратора на Windows для порта 502).

### 2. Запуск клиента (в другой консоли/вкладке)
```bash
cd Client
dotnet run
# или в Visual Studio: нажать F5 и выбрать Client
```

Клиент подключится к серверу и начнёт отображать таблицу переменных:
- **Coils[0-9]**: состояние булевых переменных (ON/OFF)
- **Registers**: типизированные данные (INT, REAL, STRING, DATE, DWORD)

Таблица обновляется каждые 500 мс без засорения консоли.

## Архитектура и дизайн

### Server-сторона
- **ModbusServer**: базовый Modbus TCP сервер из библиотеки ModbusRx
- **ModbusServerDataManager**: менеджер данных, инкапсулирует логику симуляции
  - `InitializeData()`: инициализация памяти
  - `SimulateCoilsCycle()`: циклическое включение/выключение Coils
  - `SimulateRegistersWithTypes()`: генерирование разных типов данных

### Client-сторона
- **ModbusIpMaster**: Modbus TCP клиент из библиотеки ModbusRx
- **ModbusClientDataReader**: асинхронное чтение данных
  - `ReadCoilsAsync()`: читает Coils
  - `ReadRegistersAsync()`: читает Holding Registers
  - `ReadAllDataAsync()`: читает всё одновременно (параллельно)
- **RegistersDecoder**: декодирование raw регистров в типы
  - `DecodeInt()`, `DecodeReal()`, `DecodeString()`, `DecodeDate()`, `DecodeDword()`
- **ModbusDataDisplay**: форматирование и вывод
  - `Update()`: сыром виде (для отладки)
  - `UpdateWithTypes()`: типизированные данные (для работы)

## Интеграция с CodeSys 3.5 SP17

Для подключения виртуального ПЛК CodeSys как Modbus Slave смотрите инструкцию в файле **CODESYS_SETUP.md**.

- .NET 10 SDK
- ModbusRx NuGet пакет (версия 1.1.2 или выше)
- Windows (для запуска на порту 502 требуются права администратора)

## Обработка ошибок

- Если клиент не может подключиться к серверу, он выведет сообщение об ошибке с рекомендациями
- Если сервер упадёт, клиент продолжит пытаться переподключиться каждые 500 мс
- Все ошибки логируются в консоль в формате `[ERROR] Type: Message`

## Производительность

- Частота обновления: 500 мс (2 раза в секунду)
- Асинхронная архитектура: не блокирует основной поток
- Поддержка одновременного чтения Coils и Registers (параллельные запросы)
