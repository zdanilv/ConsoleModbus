# Инструкция: Подключение клиента к виртуальному ПЛК Codesys (Control Win) — Modbus TCP

Ниже приведены шаги для настройки виртуального ПЛК в CodeSys 3.5 SP17 и маппирования переменных на адреса Modbus:

1. Установка и запуск Codesys Control Win
   - Установите Codesys 3.5 SP17 и пакет Codesys Control Win (виртуальный runtime).
   - Запустите Codesys Control Win и создайте новый контроллер.

2. Настройка Modbus TCP Slave
   - В проекте Codesys добавьте устройство "Modbus TCP Slave" (или включите Modbus TCP сервер в настройках контроллера).
   - Укажите порт 502 и Unit ID = 1 (должны соответствовать параметрам сервера в проекте).

3. Маппирование переменных
   - Создайте глобальные переменные в Codesys:
	 - Coils (булевые): bCoil_0, bCoil_1, ..., bCoil_9
	 - Holding Registers (INT/WORD): iReg_0, iReg_1, ..., iReg_9
   - Привяжите каждую переменную к соответствующему Modbus адресу:
	 - Coils: адреса 0..9
	 - Holding Registers: адреса 0..9

4. Пример (в Codesys):
   - VAR_GLOBAL
	   bCoil_0 : BOOL; (* Modbus Coil 0 *)
	   bCoil_1 : BOOL; (* Modbus Coil 1 *)
	   ...
	   iReg_0 : INT;   (* Holding Register 0 *)
	   iReg_1 : INT;   (* Holding Register 1 *)
   - END_VAR

5. Запустите виртуальный контроллер
   - Включите Runtime и загрузите программу на виртуальный контроллер.

6. Подключение клиента
   - Убедитесь, что сервер (Server) из проекта запущен и слушает порт 502.
   - Запустите клиент (Client). Он подключится к 127.0.0.1:502 по умолчанию и начнёт чтение Coils 0..9 и Holding Registers 0..9.

7. Отладка
   - Проверяйте значения в Codesys и в клиенте — они должны соответствовать.
   - Если используются разные машины, указывайте IP адрес виртуального ПЛК вместо 127.0.0.1.

Примечание: настройка конкретных меню и пунктов в Codesys может отличаться в зависимости от установленных пакетов. Используйте документацию Codesys для детализации.
